1.2 Conociendo Gemini a Fondo como Copiloto de Código

2.1 El Bloc de Notas: De Procesador Plano a Entorno de Ejecución

Los sitios web más avanzados del mundo son texto plano procesado por un navegador. Entender la diferencia entre procesadores enriquecidos y editores de caracteres brutos es crucial:

Procesadores Enriquecidos (Word, WordPad, Pages)

Metadatos Ocultos que Corrompen Código

Al guardar, agregan formatos invisibles, tablas de estilo propietarias y sustituyen automáticamente caracteres técnicos (como cambiar las comillas rectas " por curvas “”). El navegador web no puede interpretar esa basura oculta.

Editores de Texto Plano (Bloc de Notas, TextEdit)

Transparencia a Nivel de Bytes

Lo que ves en pantalla es exactamente lo que se escribe en el disco duro. El navegador (Google Chrome, Edge, Safari, Firefox) lee directamente esas instrucciones sin interferencias.

2.2 Guía Procedimental: El Arte de Guardar sin Errores

El error recurrente del docente novato es guardar el archivo y descubrir que al hacer doble clic se abre la libreta de texto en vez del navegador web. Evita la "trampa del doble formato":

Paso Crucial 1

Tipo de Archivo

En la ventana Guardar como..., cambia el campo Tipo de Documentos de texto (*.txt) a:

Todos los archivos (*.*)

Si lo omites, Windows creará archivo.html.txt inutilizándolo.

Paso Crucial 2

Nombre con Extensión

Escribe el nombre deseado seguido obligatoriamente de .html (ej. clase_ciencias.html).

mi_presentacion.html

Regla de oro: sin espacios, sin tildes ni caracteres extraños.

Paso Crucial 3

Codificación Universal

En la lista inferior Codificación, corrobora que esté seleccionada la norma:

UTF-8

Evita que la letra 'ñ' y los acentos aparezcan rotos como Ã³.

Resultado Exitoso: El archivo mostrará el ícono de tu navegador favorito. Al hacerle doble clic, abrirá localmente con la ruta file:///C:/Users/.../clase_ciencias.html al instante sin internet.

3.1 Anatomía de un Documento HTML Explicada

La web se construye como una estructura de cajas dentro de otras cajas:

<!DOCTYPE html>

<html lang="es">

  <head>

    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Clase: Ecosistemas</title>

    <style>

      body { background: #0f172a; color: white; font-family: sans-serif; }

      .slide { background: #1e293b; padding: 20px; border-radius: 12px; }

    </style>

  </head>

  <body>

    <div class="slide">

      <h1>Ecosistemas Terrestres</h1>

      <p>Comunidad biológica interactuando con su medio...</p>

    </div>

  </body>

</html>

<!DOCTYPE html> y <html lang="es"> Le avisa al navegador que debe interpretar HTML5 moderno y declara el idioma para los lectores de pantalla asistiva.
<head> (Cabecera Invisible) Contiene instrucciones técnicas: el mapa de caracteres (UTF-8), escala móvil (viewport), título de pestaña y estilos visuales CSS (<style>).
<body> (Cuerpo Visible Proyectable) Todo lo que el alumno ve: encabezados jerárquicos (<h1>-<h6>), párrafos (<p>), enlaces (<a>) y cajas contenedoras (<div>).

Prevención de Errores Críticos

3.2 Lista de "Qué NO Hacer" (Errores que Rompen tu Presentación)

Los 5 descuidos técnicos más comunes que inutilizan los recursos digitales docentes:

1. Rutas Locales Absolutas

Nunca pongas src="C:\Users\MiPc\foto.jpg". Solo existe en tu disco duro; en la escuela la imagen saldrá como un recuadro roto. Usa emojis o rutas relativas.

2. Comillas Curvas de Word

Word convierte automáticamente las comillas rectas técnicas " en curvas “”. El navegador web no las reconoce e ignora los estilos.

3. Etiquetas Huérfanas

Abrir <style> o <div> y olvidar el cierre (</style> o </div>) deja la pantalla en blanco o traga el texto.

4. Texto sin Definir Fondo

Si pones texto blanco pero no fuerzas el fondo en negro, en navegadores con tema claro predeterminado el texto se vuelve 100% invisible.

5. Omitir la Codificación UTF-8

Sin <meta charset="UTF-8">, el navegador intentará adivinar la tabla de caracteres regional de la computadora, transformando "Educación" en EducaciÃ³n.

4.1 Los Tres Roles Didácticos de la IA Frente al Código

La interacción pedagógica con la IA no consiste únicamente en pedir un producto terminado, sino en articular un ciclo continuo de co-creación:

1. IA como Redactor (Escritura)

Transforma objetivos de aprendizaje, casos y secuencias didácticas en esquemas HTML5 limpios, con jerarquía visual y tarjetas de lectura.

"Genera el código HTML para..."

2. IA como Tutor (Explicación)

Si no entiendes una línea técnica (ej. display: flex;), la seleccionas en Canvas y le pides que te la explique con analogías cotidianas.

"Explica con una analogía esta regla..."

3. IA como Depurador (Corrección)

Si un botón no responde, no descartas tu material; pegas el script y le instruyes: "Corrige la función de avance y entrega el bloque funcional".

"Identifica el error de sintaxis en..."

4.2 Prompt Maestro Integral de Co-Creación (Estructura de 9 Elementos)

Estructura estandarizada para solicitar a Gemini Canvas una presentación autocontenida de alto rendimiento:

Rol: Diseñador Instruccional Senior y Desarrollador Frontend enfocado en Recursos Educativos Abiertos (OER).

Objetivo: Presentación interactiva de diapositivas en un único archivo HTML para aprender sobre: [TEMA CURRICULAR].

Contexto: Sesión presencial para estudiantes de [NIVEL/EDAD]. Se proyectará desde laptop y se compartirá por USB para estudio en casa (100% offline).

Tarea: Escribe el código HTML5 completo con: 1) Portada interactiva; 2) 3 láminas de desarrollo en tarjetas; 3) Lámina de autoevaluación con botón "Mostrar análisis"; 4) Navegación con botones Anterior/Siguiente y contador.

Criterios: Archivo único con estilos en <style> y lógica en <script>. Modo oscuro descansado (#0f172a, tarjetas #1e293b, textos legibles >18px), contraste >4.5:1 y botones desactivados en extremos.

Restricciones: Cero librerías externas (Bootstrap, Tailwind, jQuery, Google Fonts). Cero rutas absolutas o imágenes dependientes de internet. Usa iconos Unicode (🌱, ⚡, 💡) y evita scroll vertical.

Formato: Bloque integral de código HTML5 en el lienzo de Canvas, con comentarios breves de orientación.

Verificación: Comprueba <!DOCTYPE html>, UTF-8, variables de JavaScript sin errores y etiquetas bien cerradas.

Iteración: Propón 3 mejoras pedagógicas interactivas para una versión 2.0 (ej. temporizador o quiz).
